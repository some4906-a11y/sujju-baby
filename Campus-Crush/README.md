# Campus Crush — Vercel-ready game

A responsive React + Vite canvas flap game. Includes custom supplied image assets, gold pole obstacles, a game-over panel, score/best score (localStorage), synthesized background melody and loss sound.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, import the repository.
3. Framework preset: **Vite** (usually detected automatically).
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

Controls: tap/click the game or press Space / Arrow Up.
